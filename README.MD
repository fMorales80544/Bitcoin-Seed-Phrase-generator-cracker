# Bitcoin Seed Phrase Generator

```
Automated Bitcoin wallet generator. With mnemonic and passphrases bruteforces wallet addresses.
```

## BIP39 Overview

A seed phrase (mnemonic) is a human-readable representation of a wallet's master
private key. This tool generates valid BIP39 mnemonics from the 2048-word wordlist,
derives the HD wallet tree (BIP32/BIP44), and scans derived addresses for activity.

## Supported Derivation Paths

| Standard | Path | Network |
|----------|------|---------|
| BIP44 | m/44'/0'/0'/0/x | Bitcoin Legacy |
| BIP49 | m/49'/0'/0'/0/x | Bitcoin SegWit (P2SH) |
| BIP84 | m/84'/0'/0'/0/x | Bitcoin Native SegWit (bech32) |

## Generation Modes

- **Random** — Generates cryptographically random 12 or 24-word phrases
- **Partial** — Completes a phrase where some words are already known
- **Dictionary** — Tests combinations from a custom word list
- **Typo recovery** — Tries common misspellings of known words

## Output Format

Matching wallets are saved to `results.txt`:
```
seed phrase: abandon ability able about above absent absorb abstract absurd abuse access accident
derivation: m/44'/0'/0'/0/0
address: 1LoVGDgRs9hTfTNJNuXKSpywcbdvwRXpmK
balance: 0.05813200 BTC
```
